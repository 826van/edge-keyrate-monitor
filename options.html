Relay key rate monitor

Checks relay dashboards with your existing browser login. Config and results stay in this browser.

How to configure vip.lcodex.cn

Keep a normal logged-in tab open at https://vip.lcodex.cn.

Use check URL https://vip.lcodex.cn/api/user/self/groups and request mode Logged-in tab.

If it still fails, open DevTools Network, click the same API request, and copy its Authorization header source. Then set Token source/key below.

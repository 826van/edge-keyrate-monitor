Relay key rate monitor

Checks relay dashboards with your existing browser login. Config and results stay in this browser.

How to configure vip.lcodex.cn

Keep a normal logged-in tab open at https://vip.lcodex.cn.

First try request mode Page keyword scan. Fill Dashboard / key page URL with the page that shows generated keys or key groups after login.

If that page is not open, the extension will open it. Log in or navigate to the right page, then click check again.

If scan cannot find enough data, switch to Logged-in tab API, use check URL https://vip.lcodex.cn/api/user/self/groups, and inspect DevTools Network for token headers if needed.
